# Keyda Business SDKs

Drop the Keyda bot into your app. One key, every platform.

| Platform | Package | Status |
|---|---|---|
| Android | `in.keyda:keyda-bot` | source here |
| iOS | `KeydaBot` (SPM / CocoaPods) | source here |
| React Native | `@keyda/bot-react-native` | source here |
| Flutter | `keyda_bot` | source here |
| Ionic / Capacitor | `@keyda/bot-capacitor` | source here |
| WordPress | `keyda-bot` plugin | source here |
| Any website | `<script src="https://business.keyda.in/widget.js">` | shipped |

Every one of these opens the same hosted chat page, so a change an owner makes
in their dashboard is live everywhere at once. See [CONTRACT.md](CONTRACT.md)
for what that means and what it costs.

Get your client id from **Install** in the [Keyda Business
dashboard](https://business.keyda.in/app/).
