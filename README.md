# Keyda Business SDKs

Drop the Keyda bot into your app. One key, every platform.

| Platform | Package | Status |
|---|---|---|
| Android | `in.keyda:keyda-bot` | JitPack `com.github.KeydaAI:keyda-business-sdks:v0.1.4` |
| iOS | `KeydaBot` (SPM / CocoaPods) | SPM from this repository at tag `v0.1.4` |
| React Native | `@keyda/bot-react-native` | npm `@keyda/bot-react-native@0.1.4` |
| Flutter | `keyda_bot` | pub.dev `keyda_bot ^0.1.4` |
| Ionic / Capacitor | `@keyda/bot-capacitor` | npm `@keyda/bot-capacitor@0.1.4` |
| WordPress | `keyda-bot` plugin | source here (`wordpress/keyda-bot/`, 0.1.4) |
| Any website | `<script src="https://keyda.in/business/widget.js">` | shipped |

Every one of these opens the same hosted chat page, so a change an owner makes
in their dashboard is live everywhere at once — including its theme: light,
dark or "match the visitor" is set in the dashboard, the page carries it, and
the native SDKs match their status bar and close control to it (no theme
option on any SDK). See [CONTRACT.md](CONTRACT.md) for what that means and
what it costs.

Get your client id from **Install** in the [Keyda Business
dashboard](https://keyda.in/business/app/).
